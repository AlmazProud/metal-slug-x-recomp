## Precision: code that MAME proved to be data

MAME recorded 12,992 P1 words read as data rather than as instructions.
Bytes marked as code that fall on those words, by evidence:

| Evidence | Code bytes | Certain false positives |
|---|---:|---:|
| Confirmed | 201,888 | 0 |
| Heuristic A (pointer in code) | 202,062 | 0 |
| Heuristic B (pointer table) | 99,458 | 0 |

This is a lower bound: it only detects data the game read during the trace. In the combined
analysis, heuristic paths that would overlap that data are cut (0 cuts), so these should be 0
here. The purely static validation does not use this information.
